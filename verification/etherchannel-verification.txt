CCNA Enterprise Branch Office Lab
EtherChannel / LACP Verification
Devices: DSW1 and DSW2
================================================================

PURPOSE
-------

This verification demonstrates the Layer 2 EtherChannel operating
between the two distribution switches, DSW1 and DSW2.

Two physical Gigabit Ethernet interfaces are combined into
Port-channel1 using the Link Aggregation Control Protocol (LACP).

The EtherChannel provides increased aggregate bandwidth and link
redundancy between the distribution switches.


================================================================
ETHERCHANNEL DESIGN
================================================================

                 DSW1                         DSW2

             Gi0/3 ----------------------- Gi0/3
                    \                     /
                     \                   /
                      === Port-channel1 ===
                     /                   \
                    /                     \
             Gi1/2 ----------------------- Gi1/2


Channel Group:
  1

Logical Interface:
  Port-channel1

Protocol:
  LACP

Physical Member Interfaces:
  GigabitEthernet0/3
  GigabitEthernet1/2

EtherChannel Type:
  Layer 2

Aggregate Bandwidth:
  2,000,000 Kbit/sec

Port-channel1 is used as an 802.1Q trunk between DSW1 and DSW2.

================================================================
LACP CONFIGURATION RELATIONSHIP
================================================================

The implemented configuration uses:

DSW1:
  channel-group 1 mode active

DSW2:
  channel-group 1 mode passive

LACP active mode initiates LACP negotiation.

LACP passive mode responds to received LACP negotiation messages.

The active/passive combination successfully forms the EtherChannel,
as confirmed by both switches reporting:

  Po1(SU)
  Gi0/3(P)
  Gi1/2(P)


================================================================
BANDWIDTH VERIFICATION
================================================================

Each physical member is a Gigabit Ethernet interface.

Physical links:

  Gi0/3 = 1 Gbit/sec
  Gi1/2 = 1 Gbit/sec

Port-channel1 reports:

  BW 2000000 Kbit/sec

This represents an aggregate logical bandwidth of:

  2 Gbit/sec

EtherChannel distributes traffic flows across the member links
according to the platform's EtherChannel load-balancing method.

A single traffic flow is not necessarily transmitted at 2 Gbit/sec;
the bundle provides aggregate capacity across multiple flows while
also providing link redundancy.

================================================================
VERIFICATION RESULTS
================================================================

PASS

EtherChannel verification confirms:

  - Port-channel1 is operational on DSW1.
  - Port-channel1 is operational on DSW2.
  - Port-channel1 is a Layer 2 EtherChannel.
  - LACP is the negotiation protocol.
  - GigabitEthernet0/3 is bundled successfully.
  - GigabitEthernet1/2 is bundled successfully.
  - Both member links show the P bundled flag.
  - The logical Port-channel interface is up/up on both switches.
  - Aggregate bandwidth is reported as 2 Gbit/sec.
  - No input, CRC, output, or collision errors are present.
  - DSW1 active and DSW2 passive LACP modes successfully negotiate
    the bundle.


================================================================
CONCLUSION
================================================================

The LACP EtherChannel between DSW1 and DSW2 is operating
successfully.

Two Gigabit Ethernet physical links have been combined into the
single logical Port-channel1 interface.

The bundle provides additional aggregate bandwidth and physical-link
redundancy between the two distribution switches while allowing
Spanning Tree to treat the EtherChannel as a single logical Layer 2
connection.
