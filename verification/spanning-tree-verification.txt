================================================================
CCNA Enterprise Branch Office Lab
Rapid PVST+ / Spanning Tree Verification
Devices: DSW1 and DSW2
================================================================

PURPOSE
-------

This verification demonstrates Rapid PVST+ root-bridge placement
across the redundant distribution layer.

The network uses DSW1 and DSW2 as the primary Spanning Tree control
points for the enterprise VLANs.

Root-bridge responsibility is deliberately distributed between the
two distribution switches instead of assigning every VLAN to the
same root bridge.

This provides practical verification of:

  - Rapid PVST+ operation
  - Root bridge election
  - Bridge priority configuration
  - Per-VLAN root selection
  - Root port selection
  - Designated port operation
  - EtherChannel interaction with Spanning Tree

CONFIGURED DISTRIBUTION-SWITCH PRIORITIES
================================================================

DSW1:

  VLAN 10:   24576
  VLAN 30:   24576
  VLAN 999:  24576

  VLAN 20:   28672
  VLAN 99:   28672


DSW2:

  VLAN 10:   28672
  VLAN 30:   28672
  VLAN 999:  28672

  VLAN 20:   20480
  VLAN 99:   20480


Lower Spanning Tree bridge priority values are preferred during
root-bridge election.

The configured priorities therefore intentionally make:

  DSW1 preferred for VLANs 10, 30, and 999.

  DSW2 preferred for VLANs 20 and 99.


================================================================
SYSTEM-ID EXTENSION
================================================================

Rapid PVST+ incorporates the VLAN ID into the displayed bridge
priority using the extended system ID.

For example:

DSW1 VLAN 10:

  Configured priority: 24576
  VLAN ID:             10

Displayed priority:

  24576 + 10 = 24586


DSW2 VLAN 20:

  Configured priority: 20480
  VLAN ID:             20

Displayed priority:

  20480 + 20 = 20500

The displayed priorities in the operational output therefore differ
slightly from the configured base priorities.

================================================================
PORT-CHANNEL STP BEHAVIOR
================================================================

Port-channel1 appears as one logical interface in the Spanning Tree
topology.

When DSW1 is the root bridge:

  DSW1:
    Po1 = Designated Forwarding

  DSW2:
    Po1 = Root Forwarding

This occurs for:

  VLAN 10
  VLAN 30
  VLAN 999


When DSW2 is the root bridge:

  DSW2:
    Po1 = Designated Forwarding

  DSW1:
    Po1 = Root Forwarding

This occurs for:

  VLAN 20
  VLAN 99


The physical EtherChannel member interfaces do not appear separately
in this Spanning Tree output.

Spanning Tree treats the LACP EtherChannel as the single logical:

  Port-channel1

interface.


================================================================
ROOT PATH COST
================================================================

On the non-root distribution switch, the root path uses:

  Port-channel1

with a cost of:

  3

Example:

DSW2 VLAN 10:

  Root ID Cost: 3
  Root Port:    Port-channel1

DSW1 VLAN 20:

  Root ID Cost: 3
  Root Port:    Port-channel1

This confirms that the inter-distribution EtherChannel provides the
preferred Layer 2 path toward the root bridge.


================================================================
RAPID PVST+ OPERATION
================================================================

The output reports:

  Spanning tree enabled protocol rstp

for each verified VLAN.

This confirms Rapid Spanning Tree operation within the per-VLAN
Spanning Tree design.

The distribution-layer ports shown in the captured output are in the
Forwarding state.

Access-layer alternate or blocking port behavior is verified
separately from the access switches when required.


================================================================
VERIFICATION RESULTS
================================================================

PASS

Rapid PVST+ verification confirms:

  - DSW1 is Root Bridge for VLAN 10.
  - DSW2 is Root Bridge for VLAN 20.
  - DSW1 is Root Bridge for VLAN 30.
  - DSW2 is Root Bridge for VLAN 99.
  - DSW1 is Root Bridge for VLAN 999.
  - Root placement matches the intended per-VLAN design.
  - Configured bridge priorities determine the preferred roots.
  - Extended system IDs correctly incorporate the VLAN number into
    the displayed bridge priority.
  - Port-channel1 is treated as one logical Spanning Tree interface.
  - The non-root distribution switch uses Port-channel1 as its Root
    Port.
  - The root distribution switch uses Port-channel1 as a Designated
    Forwarding port.
  - The inter-distribution path is forwarding for all tested VLANs.


================================================================
CONCLUSION
================================================================

The Rapid PVST+ distribution-layer design is operating as intended.

Root-bridge responsibility is deliberately divided between DSW1 and
DSW2:

  DSW1:
    VLAN 10
    VLAN 30
    VLAN 999

  DSW2:
    VLAN 20
    VLAN 99

This design demonstrates deliberate per-VLAN Spanning Tree root
placement while maintaining redundant Layer 2 connectivity through
the distribution layer.

The operational output also demonstrates the integration between
Rapid PVST+ and the LACP EtherChannel connecting DSW1 and DSW2.
